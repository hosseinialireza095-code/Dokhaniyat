# حساب دخانیات — نسخه اولیه کد منبع

این بسته **APK نیست**. یک نمونه کد Flutter و ساختار پایگاه داده Supabase برای ورود سه کاربر، نمایش موجودی مشترک و ثبت فروش نخی/پاکتی/باکسی است. هنوز برای استفاده واقعی در مغازه آماده نیست.

## راه‌اندازی توسعه‌دهنده
1. Flutter SDK و Android SDK را نصب کنید.
2. در پوشه پروژه دستور `flutter create --platforms android .` و سپس `flutter pub get` را اجرا کنید.
3. یک پروژه Supabase بسازید و محتوای `supabase/schema.sql` را در SQL Editor اجرا کنید.
4. سه کاربر را از بخش Authentication بسازید (ثبت‌نام عمومی را در صورت نیاز غیرفعال کنید).
5. با دسترسی مدیریتی و فقط در SQL Editor یک مغازه در `shops` ایجاد کنید؛ شناسه‌های سه کاربر را در `shop_members` برای همان مغازه ثبت کنید؛ سپس کالاهای اولیه را در `products` درج کنید. به‌جای service_role key، فقط کلید عمومی/anon را در اپ استفاده کنید.
6. با دستور زیر اجرا کنید:
   `flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLIC_KEY`
7. برای خروجی نصب: `flutter build apk --release` (پس از تنظیم امضای برنامه و آزمایش).

## محدودیت‌های فعلی
- ثبت خرید، هزینه، نسیه، مدیریت شرکا، گزارش‌های مالی، بارکد و پشتیبان‌گیری هنوز پیاده‌سازی نشده‌اند.
- افزودن و ویرایش کالا فعلاً فقط از پنل مدیریت Supabase امکان‌پذیر است.
- فروش فقط در حالت آنلاین انجام می‌شود؛ همگام‌سازی پس از اتصال و دریافت رویداد انجام می‌شود، نه با تضمین زمان ثابت.
- برای محیط واقعی باید ثبت تکراری درخواست (idempotency)، حسابرسی تغییرات، کنترل دقیق نقش‌ها، بازگشت کالا، تست همزمانی، مالیات و مقررات محلی، و سیاست نگهداری/پشتیبان‌گیری تکمیل شوند.
- برای قیمت و واحدهای هر کالا، مقادیر واقعی را تنظیم کنید. `stock_sticks` موجودی را بر حسب نخ نگه می‌دارد.
- طرح رایگان سرویس ممکن است محدودیت و تغییر شرایط داشته باشد.
